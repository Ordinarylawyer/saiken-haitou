# <img src="site/favicon.svg" width="40" height="40" alt="" align="top"> saiken-haitou

債権執行の配当額を計算し、実務の書式で配当表（弁済金交付計算書）を作る Web アプリです。**ブラウザの中だけで動き、入力した情報をどこにも送りません。**

**アプリを開く：[債権執行 配当計算](https://ordinarylawyer.github.io/saiken-haitou/)**

姉妹版：[不動産執行 配当計算](https://ordinarylawyer.github.io/kenu-haitou/)

## 使い方

上のアプリの URL を開くか、`site/index.html` をブラウザ（Edge・Chrome）で直接開きます。はじめは「テンプレートから始める」で、配当事件（リ事件）の数と債権者の構成（一般債権どうし／一般債権＋養育費（先取特権あり・なし）／一般債権＋養育費＋公債権）を選ぶと、典型的な形の入力欄と、次に入れるものの一覧が出ます。差押債権は、預金・売掛金などと給料等の両方を選んで、それぞれの事件の数を入れられます。同じ枠の「設例から選ぶ」からは、テストで結果を確かめている設例（41件）を読み込めます。読み込むと、計算の結果がテストの期待値と一致していることを表示し、そのまま書き換えてテンプレートの代わりに使えます。左で事件・配当原資・手続費用・債権者を入れると、右に配当表が出ます。「印刷（A4横）」で印刷・PDF 化（ページ番号と開始番号、2ページ目以降の列の見出しを選べます。ブラウザのヘッダ・フッタは出ません）、「Excel で保存」で .xlsx にできます。続きをするときは「JSON に保存」「JSON を読み込む」を使います。

## 扱えるもの

- 一般債権・扶養義務等債権（子の監護費用の先取特権を含む）・一般先取特権・担保権（抵当権の物上代位・債権質権・特別の先取特権）・租税・公課・仮差押え
- 給料等の差押えの範囲の違い（1/4・1/2、33万円の調整、滞納処分の差押えがあるときの国税徴収法76条の範囲）と、参加者の少ない部分から先に配る計算（非競合部分先行充当）。預金・売掛金などと給料等の両方を差し押さえた事件では、供託金ごとに種類を選ぶ
- 子の監護費用の先取特権（月8万円×子の数、施行日前の取決めの経過措置）
- 担保権と租税の優劣（法定納期限等と設定登記等の先後）、優劣が循環する場合の国税徴収法26条の計算、抵当権の物上代位の相対的優劣（吸収方式）
- 供託費用・手続費用（手続費用計算書も作れる）・供託利息、配当要求の終期後の参加の除外、仮差押え・支払留保の供託、弁済金交付計算書との切替え
- 供託ごとの配当加入と配当加入等の状況表（第三債務者が多数のときは第三債務者単位でまとめる）
- 担保権・先取特権の利息・損害金のうち最後の2年分を超える部分（一般債権と同順位）、合意配当、混合供託（還付請求権が債務者に属することの証明前は参考計算として警告）

## 入力を外に出さないために

- 計算と Excel の作成は、すべてブラウザの中で行います。`index.html` の CSP で外部との通信を禁止しています（`connect-src 'none'` など）。
- 外部の CDN・フォント・アクセス解析、ブラウザの保存領域（localStorage など）・Cookie は使いません。
- これらは `tests/privacy.mjs` で確かめています。

## 誤りの報告・改善の提案

- 計算の誤りに気づいたら、アプリの配当表の下にある「この計算の誤りを報告」から Issue を作ってください（GitHub のアカウントが必要です）。機能や画面の改善は「改善を提案」からどうぞ。
- 事件の当事者名・事件番号など、事件を特定できる情報は書かないでください。入力を添えるときは、アプリの「名前等を消した JSON を保存」で保存したファイルを使ってください。
- 直し方がわかる場合は Pull Request を歓迎します。手順は [CONTRIBUTING.md](CONTRIBUTING.md) にあります。

## 参考文献

- 近藤基「債権配当の実務と書式〔第3版〕」181～221頁（民事法研究会・2021年）（XV 配当表および弁済金交付計算書の記載事項について、XVI 比較的複雑な配当における配当表の見方について）。配当表の書式、配当加入等の状況表、按分の端数を小数点以下の大きい債権者から切り上げる扱い（187頁）はこれによる。テストに同書の参考例 XV-1〜XV-3・XV-5・XVI-1・XVI-3・XVI-4 の数値を使っている
- 園部厚「書式 債権・その他財産権・動産等執行の実務〔全訂15版〕」447頁（民事法研究会・2020年）。手続費用計算書の書式（書式2-72）はこれによる
