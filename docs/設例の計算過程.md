# 設例の計算過程

アプリの「テンプレート・設例」→「設例から選ぶ」にある設例について、どの債権者にいくら配るかを、入力・計算の過程・結果の順に説明する。各設例の結果は、エンジンのテストで1円単位まで確かめている。

- 金額は円。債務者は S、債権者は A・B・C、X・Y などの符号で表す（公租公課は国・市・○○県など）。
- 「入力の要点」「部分ごとの配分」「結果」の表は、設例をアプリの計算エンジンで計算して作っている。「計算の過程」は、その計算を手で追えるように書いたもの。
- 近藤基「債権配当の実務と書式〔第3版〕」181～221頁（民事法研究会・2021年）の参考例を基にした設例は、計算の結果が変わらないよう金額・日付はそのままにし、名前を符号に置き換えている。
- 論点の番号は [論点整理](論点整理.md) の番号で、結論の根拠（条文・判例・文献）はそちらにまとめている。

## 計算の共通の流れ

1. **配当に加わる債権者を決める。** 供託金ごとに、差押え・仮差押えの執行・配当要求・交付要求の効力が、配当要求の終期（第三債務者の供託の時など）までに生じた債権者が加わる（民執法165条。論点1-3・1-4）。
2. **配当原資を求める。** 供託金に供託利息を加え、手続費用（配当期日呼出状及び支払委託書の送付費用など）を先に差し引く（論点4-1）。
3. **給料等の供託金は、差し押さえられる範囲ごとに分ける。** 手取額の1/4までの部分（一般の差押え）、1/4を超え1/2までの部分（扶養義務等債権だけ）、国税徴収法76条の範囲（滞納処分の差押え）に分け、加わる債権者の少ない外側の部分から配る。内側の部分では、外側で受けた後の残額を按分の基礎にする（民執法152条。論点3-1〜3-4）。
4. **各部分では、順位の高い債権者から債権額の全額を配る。** 同順位の債権者の間では、配る額を債権額（残額）の割合で按分する（論点整理の第4）。
5. **按分の端数。** 各債権者の額の1円未満を切り捨て、配る額に足りない分を、切り捨てた小数点以下の数の大きい債権者から1円ずつ加える（論点7-3）。
6. **充当。** 配当額は、各債権の費用→利息→損害金→元金の順に充てる（民法489条。論点7-1）。
7. **書面の種類。** 債権者が1人のとき、又はどの部分でも取り合い（複数の債権者が加わり、配る額が足りないこと）が生じないときは弁済金交付計算書、それ以外は配当表になる（民執法166条2項・84条。論点1-1）。全額を払って残りがあれば、剰余金として債務者に交付する。

## 一般債権・弁済金交付・合意配当

### 1 一般債権3人で按分

預金100万円に一般債権者3人が競合。手続費用を先に償還し、残りを債権額で按分する（端数は小数点以下の大きい者から）。

関係する論点：[1-1](論点整理.md#第1-手続の分岐と配当加入)・[7-3](論点整理.md#第7-債権額充当端数配当表の記載)　設例の番号：`gen-basic`

**入力の要点**

- 配当期日：令和8年12月10日
- 債務者：S
- 手続費用：6,000（予納者 X）

| 供託金 | 供託日 | 供託金額 | 供託利息 | 内容 |
| --- | --- | ---: | ---: | --- |
| 1 | 令和8年11月1日 | 1,000,000 | 0 |  |

| 債権者 | 種別 | 債権の種類 | 差押え等の効力発生・申立て | 請求債権 | その他 |
| --- | --- | --- | --- | ---: | --- |
| X | 一般債権 | 貸金 | 申立て 令和8年1月10日 | 1,240,000 |  |
| Y | 一般債権 | 貸金 | 申立て 令和8年2月10日 | 800,000 |  |
| Z | 一般債権 | 貸金 | 申立て 令和8年3月10日 | 360,000 |  |

**計算の過程**

1. 3人とも供託の前に差し押さえているので、全員が配当に加わる。
2. 配当原資：1,000,000 − 6,000 ＝ 994,000（手続費用は第1順位で、先に償還する）。
3. 3人とも一般債権で同順位なので、994,000 を債権額（1,240,000 ＋ 800,000 ＋ 360,000 ＝ 2,400,000）の割合で按分する。
   - X：994,000 × 1,240,000 ÷ 2,400,000 ＝ 513,566.66…
   - Y：994,000 × 800,000 ÷ 2,400,000 ＝ 331,333.33…
   - Z：994,000 × 360,000 ÷ 2,400,000 ＝ 149,100
4. 端数：切り捨てると 513,566 ＋ 331,333 ＋ 149,100 ＝ 993,999 で1円足りない。小数点以下の最も大きいX（.66…）に1円を加えて 513,567 とする。
5. 3人が取り合うので、配当表になる。

**部分ごとの配分**（按分の基礎は、その部分を配る前の各債権の残額）

| 部分 | 範囲 | 配る額 | 配当に加わる債権者（按分の基礎） | 配当額 | 残り |
| --- | --- | ---: | --- | --- | ---: |
| 供託金1 | 全額 | 1,000,000 − 費用 6,000 ＝ 994,000 | X（1,240,000）、Y（800,000）、Z（360,000） | X 513,567、Y 331,333、Z 149,100 | 0 |

**結果**：配当表

| 順位 | 債権者 | 債権の種類 | 債権額 | 配当額 | 充当（費用・利息・損害金・元金） | 備考 |
| --- | --- | --- | ---: | ---: | --- | --- |
| 1 | X | 手続費用 | 6,000 | 6,000 |  | 配当期日呼出状及び支払委託書送付費用 |
| 2 | X | 貸金 | 1,240,000 | 513,567 | 0・0・0・513,567 |  |
| 2 | Y | 貸金 | 800,000 | 331,333 | 0・0・0・331,333 |  |
| 2 | Z | 貸金 | 360,000 | 149,100 | 0・0・0・149,100 |  |
|  | 合計 |  |  | 1,000,000 |  |  |

### 2 同順位の按分と充当（配当表例1）

一般債権者3人。供託利息を加え、手続費用を償還した残りを按分し、費用・利息・損害金・元金の順に充当する。

出典：近藤基「債権配当の実務と書式〔第3版〕」192頁（民事法研究会・2021年）の参考例XV-1（配当表例1）を基に、計算の結果が変わらないよう金額・日付はそのままにし、名前を符号に置き換えたもの

関係する論点：[7-1](論点整理.md#第7-債権額充当端数配当表の記載)・[7-3](論点整理.md#第7-債権額充当端数配当表の記載)　設例の番号：`book-xv1`

**入力の要点**

- 配当期日：令和8年11月19日
- 債務者：S
- 手続費用：1,871（予納者 A）

| 供託金 | 供託日 | 供託金額 | 供託利息 | 内容 |
| --- | --- | ---: | ---: | --- |
| 1 | 令和8年1月1日 | 376,211 | 87 |  |

| 債権者 | 種別 | 債権の種類 | 差押え等の効力発生・申立て | 請求債権 | その他 |
| --- | --- | --- | --- | ---: | --- |
| A | 一般債権 | 貸金 | 申立て 令和7年1月1日 | 357,637（費用 6,660、損害金 10,977、元金 340,000） |  |
| B | 一般債権 | 貸金 | 申立て 令和7年2月1日 | 324,557（費用 3,000、利息 12,785、損害金 58,772、元金 250,000） |  |
| C | 一般債権 | 貸金 | 申立て 令和7年3月1日 | 455,000 |  |

**計算の過程**

1. 配当原資：376,211 ＋ 87 − 1,871 ＝ 374,427（供託利息を加え、手続費用を差し引く）。
2. 按分の基礎は、各債権の費用・利息・損害金・元金の合計。A 6,660 ＋ 10,977 ＋ 340,000 ＝ 357,637、B 3,000 ＋ 12,785 ＋ 58,772 ＋ 250,000 ＝ 324,557、C 455,000。合計 357,637 ＋ 324,557 ＋ 455,000 ＝ 1,137,194。
3. 按分：
   - A：374,427 × 357,637 ÷ 1,137,194 ＝ 117,753.83…
   - B：374,427 × 324,557 ÷ 1,137,194 ＝ 106,862.06…
   - C：374,427 × 455,000 ÷ 1,137,194 ＝ 149,811.10…
4. 端数：切り捨てた合計 117,753 ＋ 106,862 ＋ 149,811 ＝ 374,426 で1円足りないので、小数点以下の最も大きいA（.83…）に加えて 117,754。
5. 充当（費用→利息→損害金→元金）：Aは 117,754 − 6,660 − 10,977 ＝ 100,117 を、Bは 106,862 − 3,000 − 12,785 − 58,772 ＝ 32,305 を元金に充てる。

**部分ごとの配分**（按分の基礎は、その部分を配る前の各債権の残額）

| 部分 | 範囲 | 配る額 | 配当に加わる債権者（按分の基礎） | 配当額 | 残り |
| --- | --- | ---: | --- | --- | ---: |
| 供託金1 | 全額 | 376,211 ＋ 利息 87 − 費用 1,871 ＝ 374,427 | A（357,637）、B（324,557）、C（455,000） | A 117,754、B 106,862、C 149,811 | 0 |

**結果**：配当表

| 順位 | 債権者 | 債権の種類 | 債権額 | 配当額 | 充当（費用・利息・損害金・元金） | 備考 |
| --- | --- | --- | ---: | ---: | --- | --- |
| 1 | A | 手続費用 | 1,871 | 1,871 |  | 配当期日呼出状及び支払委託書送付費用 |
| 2 | A | 貸金 | 357,637 | 117,754 | 6,660・0・10,977・100,117 |  |
| 2 | B | 貸金 | 324,557 | 106,862 | 3,000・12,785・58,772・32,305 |  |
| 2 | C | 貸金 | 455,000 | 149,811 | 0・0・0・149,811 |  |
|  | 合計 |  |  | 376,298 |  |  |

### 4 剰余金を債務者へ（弁済金交付計算書例3）

全額を弁済でき、残りは債務者に交付する。

出典：近藤基「債権配当の実務と書式〔第3版〕」200頁（民事法研究会・2021年）の参考例XV-5（弁済金交付計算書例3）を基に、計算の結果が変わらないよう金額・日付はそのままにし、名前を符号に置き換えたもの

関係する論点：[1-1](論点整理.md#第1-手続の分岐と配当加入)　設例の番号：`book-xv5`

**入力の要点**

- 配当期日：令和8年10月10日
- 債務者：S
- 手続費用：628（予納者 A）

| 供託金 | 供託日 | 供託金額 | 供託利息 | 内容 |

### 13 養育費だけが取れる部分の配当と先取特権の被担保債権額
